# 通过 MCP 解锁专业功能

**模型上下文协议 (MCP) 将 Cline 连接到充满强大工具的世界。**

Go beyond local code. With the Model Context Protocol (MCP), Cline accesses vital context from external datasources like databases and APIs. Configure local or remote MCP servers to give Cline specialized, secure tools for complex, real-world development tasks.\n
